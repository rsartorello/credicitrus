Painel CMS — Guia de uso

Tutorial do painel administrativo do novo site Credicitrus: acesso, publicação de conteúdo, banners e usuários.
Versão 1.0 · 09/09/2026 · Destinatário: equipe Credicitrus / editores de conteúdo

1. O que é o CMS

O CMS é o painel em /admin usado para gerenciar conteúdos exibidos no site público — principalmente a área de Transparência e os banners da home — sem alterar código.

Site público
Páginas que o cooperado e o visitante acessam.
Painel CMS
Área restrita para cadastrar, editar, publicar e excluir conteúdos.

4. Fluxo padrão (documentos)

Em Relatórios, Normativos, Ética, Tarifas e Assembleias o fluxo é o mesmo:

  1. Abra o módulo no menu.
  2. Veja a lista Itens cadastrados.
  3. Clique em Novo… para criar (abre página dedicada).
  4. Preencha título/dados, envie o PDF (ou informe link externo, quando disponível).
  5. Marque Publicado se o item deve aparecer no site.
  6. Salve. O item volta para a lista.
  7. Use o ícone de lápis para editar, olho para publicar/despublicar, lixeira para excluir.
Exclusão: pede confirmação em duas etapas no modal. A ação é permanente.
Tarifas: além de publicar, use o ícone de estrela para definir o arquivo vigente (é o que aparece no Header/Rodapé do site).

5. Banners da home

  1. Menu Banners → Nova campanha.
  2. Envie imagem desktop (obrigatória) e mobile (opcional).
  3. Preencha título, CTA (texto + link), ordem e datas de vigência, se houver.
  4. Publique para exibir no carrossel da home.

Dica: use imagens leves (WebP/JPG otimizado) e proporção consistente para evitar cortes diferentes entre desktop e mobile.

6. Publicar vs rascunho

StatusSignificado
PublicadoVisível no site (nas páginas correspondentes)
RascunhoSalvo no CMS, mas não aparece para o público

Você pode cadastrar com antecedência em rascunho e publicar na data desejada.

7. Usuários e permissões

Apenas super-admin acessa o menu Usuários. É possível criar editores com níveis por módulo:

NívelPode
Sem acessoNão vê o módulo
VisualizarSó consulta
EditarCria e altera (sem publicar, conforme regra do módulo)
PublicarPode publicar no site

Super-admin tem acesso total, inclusive gestão de usuários.

8. Boas práticas

  • Use títulos claros e padronizados (ano, semestre, tipo do documento).
  • Confira o PDF antes de publicar (arquivo correto, legível, sem dados sensíveis indevidos).
  • Despublique conteúdos desatualizados em vez de deixar links quebrados.
  • Não compartilhe senha de super-admin; crie usuários individuais.
  • Após editar, abra a página pública correspondente e valide o resultado.
  • Em caso de erro de login repetido, aguarde alguns minutos (proteção contra tentativas).

9. Problemas comuns

SituaçãoO que fazer
Item não aparece no site Verifique se está Publicado. Em tarifas, confira se está Vigente.
Falha no upload Use PDF/imagem nos formatos aceitos e tamanho adequado; tente novamente.
Sem menu Usuários Somente super-admin vê esse módulo.
Saiu sozinho do painel Sessão expirou ou a senha foi alterada — entre novamente.
